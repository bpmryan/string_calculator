# string_calculator

This is a way for me to learn more about tests in backend coding.

A clean, production-grade implementation of the classic String Calculator Kata, fully driven by **Test-Driven Development (TDD)** principles. Built using Java 17+, Maven, and JUnit 5.

Building logic incrementally inside unit test loops is an imperative skill verified during live architectural coding evaluations. This project handles text inputs, custom variable delimiters, and negative bound safety verification through JUnit 5 execution loops. 

## Getting started

### Prerequisites
Make sure you have the following installed on your machine:
* **Java Development Kit (JDK 17 or higher)**
* **Apache Maven**

### Running the Tests
To verify the implementation and run the complete TDD test suite, execute the following command in your terminal:
```bash
mvn clean test
